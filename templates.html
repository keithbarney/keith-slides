Slide Templates

Copy-paste-ready HTML blocks for all 4 slide templates. Each renders at the correct layout — just replace the placeholder text.

How to Add a Case Study

  1. Copy the 4 slide blocks below (Hero + Detail + Detail/Wide + Wide) into slides.html
  2. Update data-slide numbers sequentially from the last existing slide
  3. Replace the case study number, title, subtitle, and all placeholder content
  4. Add a menu entry in the <nav class="menu-nav"> section with the correct data-goto value
  5. Verify the slide counter shows the new total (bottom-right corner)
