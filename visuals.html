CS1 Problem — Visual Options

"No system. No communication." — Teams building patterns in their own sandboxes.

Option 1

Sandboxes

4 rectangular regions like separate Figma canvases. Each has its own dot grid with different spacing and size. Dark voids between — no connection.

Option 2

Diverging Forks

One grid at the top splits into 3 branches going down, each mutating. Same origin, different outcomes.

Option 3

Archipelago

Organic island-shaped clusters. Each island is internally consistent but different from neighbors. Dark ocean between.

Option 4

Same But Different

4 columns side by side — each a dot grid attempting the same pattern but with visible differences in size, spacing, alignment.

Option 5

Walled Gardens

Orderly grids inside visible boundary rings. Each garden is self-consistent but incompatible. Dots stop hard at each wall.
