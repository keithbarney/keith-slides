CS2 Problem — Maze Concepts

"Three libraries. Three times the work." — Same maze, three sequential runs. Each color completes the path before the next begins.

Option 1

Maze Runner

Classic maze with dot-grid walls. A stream of dots traces the solution path — first blue, then red, then green. Completed trails stay dimly lit.

Option 2

Fade & Repeat

Same maze but each trail fades out completely before the next color begins. Emphasizes the wasted repetition — nothing carries over.

Option 3

Particle Stream

Multiple dots flow through the maze simultaneously like a current. Denser, more fluid. Each color takes a turn flooding the same path.
